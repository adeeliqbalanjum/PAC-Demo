# Peshawar Arms Company · website preview

Design preview of the new Peshawar Arms Company home page (Home V2, 13 Oct 2026), built from the client's 2026 catalogue.

- Live preview: https://adeeliqbalanjum.github.io/PAC-Demo/
- Static site: `index.html`, `css/style.css`, `js/main.js`, `assets/`
- Motion: Lenis smooth scroll, GSAP ScrollTrigger and Flip (CDN). Respects `prefers-reduced-motion`.
- Content: 15 models, 6 calibres, specifications and photos from the catalogue. No prices, no cart: enquiry and eligibility flow only.
